# Results — 2026-08-24 (Eugine Claw testing)

Tested configuration: three DGX Sparks, pairwise ConnectX-7 triangle,
wired management LAN, official `deepseek-ai/DeepSeek-V4-Flash-0731` @
`9e165c30…`, TP=3 + EP + EPLB(2), NCCL mesh, DSpark MTP=5.

Method: `scripts/measure_tps.py` for counting benchmarks (temperature=0,
thinking off, 128 generated tokens, two trials per prompt size, decode
tok/s excludes first token). Prose benchmarks use four natural-language
prompts (aviation essay, photosynthesis, lighthouse novel, microservice
comparison) at 512 generated tokens, temperature=0, thinking off, streamed
with per-stream decode rate measured after first token. Acceptance
metrics from `vllm:spec_decode_num_*` counters on `/metrics`.

shipped 0.835) plus the Mia 2× security and performance patches already
committed to this fork.

## Prose benchmark (natural language — not in the original recipe)

The FlyCockpit and Mia recipes publish only counting-style benchmarks
(predictable token sequences with 100% MTP acceptance). Real-world chat
and agent workloads use open text where the DSpark draft model cannot
predict every token. This is the first published prose measurement for
the 3× configuration.

| Metric | This 3× | Mia 2× (her tables) |
| ---: | ---: | ---: |
| Prose solo median | 42 tok/s | 68–75 tok/s |
| Prose c4 per-stream | 24 tok/s | ~44 tok/s |
| MTP acceptance (prose) | ~35% | ~60–70% |
| Mean accept length | 1.72 | ~3.5 |

Per-position acceptance (3×, prose solo, temp=0):

| Position | Acceptance |
| ---: | ---: |
| 0 | 73% |
| 1 | 46% |
| 2 | 28% |
| 3 | 15% |
| 4 | 8% |

The acceptance gap is structural in our testing: the DSpark draft model usesmean-pooled auxiliary hidden states for token prediction. Under 3-way
expert parallelism, each GPU sees sparser expert routing than under 2-way
TP, degrading the draft's prediction quality from ~65% to ~35%. No
in-recipe knob (GPU utilisation, max sequences, MTP depth, sample method,
model variant) closes this gap.

## Recommended configuration

```bash
ABLITERATED=0                    # official weights
GPU_MEMORY_UTILIZATION=0.87      # tested: +13% acceptance vs 0.835
MAX_NUM_SEQS=4                    # 4.78× concurrency at 1M
MTP_NUM_TOKENS=5                  # 100% acceptance on counting; ~35% on prose
DRAFT_SAMPLE_METHOD=probabilistic # greedy predicted worse on open text
```
